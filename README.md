# RAG PDF QA Bot

Ask questions about your PDF documents. Built with LangChain, Chroma and Gradio,
running locally on IBM Granite through Ollama, or in the cloud with Gemini.

> Based on IBM's **"Construct a QA Bot that Leverages LangChain and LLMs to Answer
> Questions from Loaded Documents"** project (IBM Skills Network).

🚧 Work in progress. Full documentation comes with the first release.
